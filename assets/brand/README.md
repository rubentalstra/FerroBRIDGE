# FerroBRIDGE brand

FerroBRIDGE is the official name (Ferro for the Rust family it shares with
FerroEHR and FerroTERM, BRIDGE for what it does). Everything here is under the
Business Source License 1.1 with the rest of the repository.

FerroBRIDGE follows the family system and takes its own mark and its own hue,
which is what FerroEHR and FerroTERM already do relative to each other. The
file set, the naming, the variants, and the raster pipeline are shared; the
mark and the palette are FerroBRIDGE's own.

## The mark

The mark is a through-arch bridge: an arch springing from two piers, a deck
crossing it, and two accent nodes sitting on the deck. It draws what the
product is. The arch and the deck are the shared mapping foundation, and the
two nodes are the two targets the bridge carries, HL7 FHIR and the OMOP Common
Data Model.

## Palette, "Indigo & Iron"

| Token | Hex | Use |
|---|---|---|
| indigo | `#4F46E5` | the arch, primary mark, accents |
| indigo-deep | `#4338CA` | the deck, hover, pressed |
| violet | `#818CF8` | the two deck nodes, highlights |
| ink | `#0F172A` | text on light |
| mist | `#F1F5F9` | text on dark |
| tile | `#0B1020` | dark tile background |
| surface | `#F8FAFC` | light surface background |

The values live in `tokens.css` as `--ferrobridge-*` custom properties. On a
dark tile the mark brightens so it holds contrast: the arch goes to `#6366F1`,
the deck to `#818CF8`, and the nodes to `#C7D2FE`.

are regenerated by the commands below, never edited on their own.

## Intrinsic size

Every icon declares `width` and `height` of **512** beside its
`viewBox="0 0 64 64"`. The viewBox is what the artwork is drawn in; the two
attributes are what a consumer that rasterizes the file takes as its natural
size. With `width="64" height="64"` a package registry stores a 64-pixel bitmap
and a listing header that wants several hundred pixels renders it blurry. The
artwork is vector and loses nothing at any size, so the cap was only those two
attributes.

`favicon.svg` is deliberately excluded and stays at 64, because a favicon wants
a small intrinsic size. The lockups keep their own natural width, since they
are drawn to a fixed aspect rather than a square.

## Typography

The wordmark is set in Bricolage Grotesque (700) with a system-sans fallback
stack, which is what the lockup and social SVGs reference. Outline the wordmark
to paths before any print use, so the artwork carries no font dependency. The
rest of the FerroBRIDGE surfaces use the system font stack in
`website/landing/style.css`.

## Usage

- Keep clear space around the mark equal to the diameter of one deck node.
- The smallest the mark reads is 16 px. Below 32 px use `favicon.svg`, which
  drops the two deck nodes because they stop reading at that size.
- Put the colour mark on light or quiet surfaces, and `ferrobridge-icon-dark.svg`
  on busy or light-photographic backgrounds.
- Use `ferrobridge-icon-mono.svg` where one colour is required; it takes the
  surrounding text colour.
- Do not recolour the mark outside the palette, stretch it, add effects, or
  rebuild the wordmark in another typeface.
- Do not redraw the arch, the deck, or the nodes. The geometry is fixed.

## Regenerating the rasters

The PNG and ICO files derive from the SVGs. Run these from the repository root
after any change to `favicon.svg` or `ferrobridge-social.svg`:

```bash
rsvg-convert -w 32 -h 32 assets/brand/favicon.svg -o assets/brand/favicon-32.png
rsvg-convert -w 16 -h 16 assets/brand/favicon.svg -o assets/brand/favicon-16.png
magick assets/brand/favicon-32.png assets/brand/favicon-16.png assets/brand/favicon.ico
rsvg-convert -w 1200 -h 630 assets/brand/ferrobridge-social.svg -o assets/brand/ferrobridge-social.png
cp assets/brand/favicon.svg website/book/theme/favicon.svg
rsvg-convert -w 32 -h 32 assets/brand/favicon.svg -o website/book/theme/favicon.png
```

`scripts/site/assemble.sh` copies this directory to `assets/brand/` of the
assembled site, so the landing page, the social card, and the favicons resolve
on <https://ferrobridge.eu/>.
